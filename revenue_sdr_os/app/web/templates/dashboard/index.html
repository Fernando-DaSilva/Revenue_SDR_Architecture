Funcionalidades Disponíveis

A base estrutural e arquitetural do **Revenue SDR OS** foi totalmente testada e consolidada de acordo com as especificações exigidas. Abaixo estão os marcos técnicos ativos:

Autenticação Híbrida Cookie + Bearer

Sessões gerenciadas de forma ultra segura usando Argon2id (backend) com emissão de tokens JWT e cookie HttpOnly com política de lax.

Branding White-Label Dinâmico por Tenant

O sistema detecta automaticamente o slug do tenant no cabeçalho ou host, aplicando as cores primária/secundária do cliente e injetando o tema DaisyUI correspondente.

Isolamento Multi-Tenant Estrito

Garante isolamento absoluto de dados. Tentativas de acessar dados de outras organizações retornam erro ou redirecionam de forma segura.

API REST Versionada v1

Toda a lógica está exposta em endpoints JSON robustos (ex: /api/v1/auth/me, /api/v1/users) para futuras integrações móveis.

Roadmap de Sprints

  • Sprint 1: Base & Core UI Fundação robusta, Multi-tenancy & DaisyUI (Concluído)
  • Sprint 2: Lead Brain Listagem de Leads, timeline e unificação de identidades
  • Sprint 3: Conversas Gerenciador de canais, chat integrado e unificação
  • Sprint 4: IA SDR Integração do motor de conversação inteligente via LLM
